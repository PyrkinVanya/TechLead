# Поэтапный план обучения по инфраструктуре и системному администрированию для техлида 1С. 

План рассчитан на 3-4 месяца при уделении 5-6 часов в неделю. Цель — не стать certified sysadmin, а получить уверенное понимание для проектирования, диагностики и управления.

Финальная цель плана:
- самостоятельно развернуть отказоустойчивый кластер 1С в виртуальной среде, диагностировать типовые сетевые и серверные проблемы, грамотно ставить задачи администраторам и принимать архитектурные решения по инфраструктуре.

# План обучения: 3 уровня (от основ к архитектуре)
## Уровень 1: Основы и настройка (Месяц 1)
Цель: Понимать, из чего состоит серверная "кухня", и уметь выполнять базовые операции.

### Базовое администрирование Windows Server (2 недели)

- Теория: Роли сервера, диспетчер серверов, управление пользователями и группами (Active Directory Basics), службы (services), диспетчер задач, монитор ресурсов, журналы событий (Event Viewer).

Практика:

1) На виртуальной машине (VirtualBox/VMware Workstation Player) установите Windows Server 2019/2022.
2) Установите СУБД MS SQL Server и Сервер 1С (можно демо-версии) на этот сервер.
3) Настройте автостарт служб 1С и SQL. Создайте отдельного пользователя для службы 1С и настройте права на папки.
4) Смоделируйте проблему: остановите службу SQL. Найдите причину в Event Viewer и восстановите работу.

### Базовое администрирование Linux (2 недели)

Теория: Почему Linux важен (производительность, стабильность для серверов). Базовая философия, структура файловой системы, основные команды терминала (cd, ls, ps, top, grep, systemctl, journalctl, nano/vi).

Практика:

1) Установите Ubuntu Server 22.04 LTS на виртуальную машину.
2) Через терминал обновите систему, установите PostgreSQL 15+.
3) Установите сервер 1С для Linux по официальной инструкции.
4) Настройте firewall (ufw), откройте только нужные порты (1540-1541, 5432 для БД).
5) апишите простой bash-скрипт, который делает дамп базы PostgreSQL и архивирует его.

## Уровень 2: Сети, виртуализация и хранение (Месяц 2)
Цель: Понимать, как компоненты связываются в сеть, и освоить основу современной инфраструктуры.

### Компьютерные сети для сисадмина (1.5 недели)

Теория: Модель OSI/TCP-IP на практике. IP-адресация, подсети, маски, шлюзы. DNS (как и почему 1С-клиент ищет сервер). Порты и фаерволы. VPN (зачем для удаленных филиалов). Протоколы HTTP/HTTPS.

Практика:
1) На своей рабочей станции вызовите ipconfig /all, ping, tracert (или traceroute в Linux) до вашего рабочего сервера 1С. Расшифруйте вывод.

2) С помощью Wireshark перехватите базовый сетевой трафик (например, ping). Попробуйте найти в нем пакеты от клиента 1С к серверу (порт 1541).

3) На виртуальном сервере Linux настройте статический IP-адрес вместо DHCP.

### Виртуализация (1.5 недели)

Теория: Зачем нужна виртуализация (изоляция, эффективное использование ресурсов, снапшоты). Гипервизоры Type 1 (ESXi, Hyper-V Server) и Type 2 (VirtualBox, Workstation). Концепция виртуальных сетей (NAT, Bridge, Host-Only).

Практика:

1) Установите VMware ESXi (бесплатная версия) или Proxmox VE на отдельную физическую машину/старый компьютер.

2) Создайте виртуальную сеть. Разверните на гипервизоре две виртуальные машины: одну с Windows (для сервера 1С), другую с Linux (для PostgreSQL). Свяжите их между собой сетью.

3) делайте снимок состояния (snapshot) виртуальной машины, "сломайте" что-то в ОС, затем откатитесь на снапшот.

### Системы хранения и резервное копирование (1 неделя)

Теория: Типы дисков (HDD, SSD, NVMe), RAID-массивы (0, 1, 5, 10), сетевые хранилища (NAS/SAN). Стратегия 3-2-1 для бэкапов: 3 копии данных, 2 разных типа носителей, 1 копия вне площадки.

Практика:

1) В диспетчере сервера Windows создайте программный RAID-массив (зеркало) из двух виртуальных дисков.

2) Настройте cron-задачу (Linux) или Планировщик заданий (Windows) на автоматическое резервное копирование каталога с файловыми базами 1С на другой виртуальный диск.

## Уровень 3: Архитектура, мониторинг и облака (Месяц 3-4)
Цель: Проектировать отказоустойчивые решения и управлять инфраструктурой как код.

### Основы облачных платформ (2 недели)

Теория: IaaS, PaaS, SaaS модели. Обзор российских облаков (Yandex Cloud, Selectel, SberCloud, VK Cloud). Ключевые сервисы: виртуальные машины, managed БД, объектное хранилище, VPC (виртуальные частные облака).

Практика:

1) Зарегистрируйтесь в Yandex Cloud (есть грант для новых пользователей).

2) Создайте VPC с подсетями. Запустите ВМ с Linux из образа marketplace (уже с предустановленным PostgreSQL).

3) Настройте группы безопасности (firewall в облаке). Привяжите статический внешний IP.

4) Разверните на этой ВМ сервер 1С и подключитесь к нему со своего рабочего компьютера.

### Мониторинг инфраструктуры (1.5 недели)

Теория: Зачем нужен мониторинг (проактивное обнаружение проблем). Метрики: загрузка CPU, память, дисковый I/O, место на диске, сетевой трафик.

Практика:

1) Разверните Zabbix или Prometheus + Grafana на отдельной виртуальной машине в вашей среде.

2) Настройте сбор метрик с вашей ВМ на Windows (через агент) и Linux. Выведите на дашборд в Grafana графики загрузки CPU и памяти.

3) Настройте простое оповещение в Telegram, если загрузка CPU > 90% более 5 минут.

### Отказоустойчивость и итоговый проект (1.5 недели)

Теория: Концепции High Availability (HA), Load Balancing, Disaster Recovery (DR). Что такое кластер серверов 1С.

Итоговая практика:

Задание: Спроектировать и развернуть отказоустойчивый стенд 1С в виртуальной/облачной среде.

1) Создайте две виртуальные машины с Windows Server, объединенные в частную сеть.

2) Установите Сервер 1С в режиме кластера на обе ВМ.

3) Разверните отдельную ВМ с PostgreSQL (или используйте managed-базу в облаке).

4) Настройте центральный сервер 1С (РАС) на одной из нод.

5) Создайте информационную базу в этом кластере.

6) Сымитируйте отказ основной рабочей серверной ноды (выключите ВМ). Убедитесь, что кластер продолжает работу на второй ноде.

## Ресурсы для обучения:
Курсы: Нетология/Stepik — "Администратор Linux", "Сетевой инженер". На YouTube: каналы «Сергей Луканин» (1С-ориентированная инфраструктура), «Тимофей Хирьянов» (Linux).

Документация: Официальные гайды от Microsoft (Windows Server), Ubuntu, 1С (развертывание кластера), Yandex Cloud.

Книги: «Компьютерные сети» Олифера, «Linux. От новичка к профессионалу» Колисниченко.

Критерий успеха
Вы прошли обучение успешно, если можете:

Устно объяснить разницу между Hyper-V и VMware и выбрать под задачу.

Понимать, что означают IP-адреса в настройках кластера 1С.

По графику в Grafana определить, что проблема "тормозов" — в нехватке оперативной памяти, а не в коде 1С.

Самостоятельно составить техническое задание для переноса сервера 1С в облако.
